# Latihan C++ — Bab 3 (Control Statements)

Latihan kuliah dari buku *C++ How to Program, 11th Edition* (Deitel). Program ditulis ulang dan dikembangkan sebagai bahan belajar; buku dan kode aslinya adalah milik penerbit/pengarang.

| File | Topik |
|---|---|
| `fig03_01.cpp` | Counter-controlled iteration: rata-rata 10 nilai (pembagian `int`) |
| `fig03_01_float.cpp` | Versi desimal (`double`) dengan validasi input |
| `fig03_02.cpp` | Sentinel-controlled iteration: jumlah nilai tidak tentu, berhenti dengan `-1` |
| `fig03_03.cpp` | Nested control statements: `if...else` di dalam `while` (lulus/gagal) |

## Compile dan jalankan

```
g++ -std=c++20 fig03_02.cpp -o fig03_02
./fig03_02
```

Ketik satu nilai per baris, tanpa koma.
